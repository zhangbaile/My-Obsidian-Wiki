# 个人知识管理Wiki

基于Andrej Karpathy的LLM Wiki模式构建的个人知识管理系统。

## 🎯 简介

这是一个使用LLM维护的个人知识管理Wiki，专门用于记录和管理个人成长、健康、心理学、自我提升等领域的知识。Wiki由Claude Code根据`CLAUDE.md`文件中的规范自动维护。

## 📁 项目结构

```
.
├── CLAUDE.md              # Wiki配置和规范
├── README.md              # 本文件
├── raw/                   # 原始资料
│   ├── diary/            # 日记和笔记
│   ├── articles/         # 网络文章
│   ├── books/            # 书籍摘录
│   ├── podcasts/         # 播客笔记
│   ├── health_data/      # 健康数据
│   └── trackers/         # 目标追踪
├── wiki/                  # Wiki内容
│   ├── index.md          # 主索引
│   ├── log.md            # 操作日志
│   ├── people/           # 人物页面
│   ├── concepts/         # 概念页面
│   ├── methods/          # 方法页面
│   ├── trackers/         # 追踪页面
│   ├── sources/          # 资料摘要
│   └── summaries/        # 综合总结
└── assets/               # 媒体资源
```

## 🚀 快速开始

### 1. 添加到新资料

将新资料放入`raw/`目录的相应子目录中：
- **日记**: `raw/diary/YYYY-MM-DD-标题.md`
- **文章**: `raw/articles/[类别]/YYYY-MM-DD-文章标题.md`
- **书籍**: `raw/books/[类别]/YYYY-MM-DD-书名-章节.md`

### 2. 处理资料

告诉Claude Code处理新资料：
```
请根据CLAUDE.md的规范处理新的资料：[资料路径]
```

### 3. 查询知识

询问关于Wiki内容的问题：
```
在wiki中搜索关于[主题]的信息
```

### 4. 维护Wiki

定期进行健康检查：
```
请根据CLAUDE.md的lint规范检查wiki的健康状况
```

## 📋 页面类型

1. **人物页面**: `wiki/people/` - 记录自己和其他重要人物
2. **概念页面**: `wiki/concepts/` - 解释重要概念
3. **方法页面**: `wiki/methods/` - 记录实用方法
4. **追踪页面**: `wiki/trackers/` - 汇总数据趋势
5. **资料摘要**: `wiki/sources/` - 原始资料的摘要
6. **综合总结**: `wiki/summaries/` - 跨领域总结

## 🔗 链接系统

Wiki使用Obsidian风格的双链：
- `[[页面名称]]` - 链接到其他页面
- 链接到不存在的页面会自动创建占位符

## 📊 查看统计

- **主索引**: `wiki/index.md` - 所有页面的目录
- **操作日志**: `wiki/log.md` - 所有操作的记录

## 🛠️ 工具集成

### Obsidian
1. 打开此目录作为Obsidian库
2. 启用图形视图查看知识网络
3. 安装Dataview插件进行高级查询

### Claude Code
1. 每次会话开始时阅读`CLAUDE.md`
2. 遵循规范进行资料处理
3. 维护索引和日志的更新

## 📈 成长路径

2. **主动探索**: 通过提问发现知识盲点
3. **综合思考**: 连接不同领域的知识
4. **行动导向**: 将知识转化为实践

## 🤖 Claude Code集成

本Wiki的设计与Claude Code深度集成：
- Claude Code理解`CLAUDE.md`中的所有规范
- 自动维护索引、日志和页面链接
- 能够进行复杂的知识综合和总结
- 支持各种格式的输出（表格、列表、图表建议）
